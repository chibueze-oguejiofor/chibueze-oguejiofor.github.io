This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Personal portfolio website for Chibueze Nnamdi Oguejiofor, hosted via GitHub Pages. Built on the Start Bootstrap "Agency" template (Bootstrap 4, SCSS, jQuery), adapted into a **multi-page site**.

## Pages

Six root HTML files. `index.html` and `contact.html` are pure meta-refresh redirects to `bio.html` (no navbar, no CSS/JS) — the old Contact page was retired in Aug 2026 (its content duplicated the footer); the redirect keeps old links alive. The four real pages are:

- `bio.html` — landing page: headshot, italic serif tagline (`.bio-tagline`: role / employer), academic-profile pill buttons (`.scholar-links`: ORCID / Google Scholar / GitHub, brand-colored hovers; ORCID icon is self-hosted `img/orcid.svg`), bio prose, academic timeline (`.bio-timeline` boxes), CV link
- `research.html` — portfolio grid (3 items, equal-height tiles) + Bootstrap modals (the RI and Turbulence modals carry the verbatim JAS abstracts as two left-aligned paragraphs inside a `div.modal-abstract`, closed by a muted italic `p.item-note` publication line)
- `publications.html` — three gray box sections (`ul.pub-list > li`, each titled by a small tracked-uppercase label `p.text-muted` over a hairline rule), each holding a `ul.pub-entries` bullet list (one `li` per publication; yellow ring bullets that fill on hover; an entry's links are grouped in a trailing `div.pub-links` block so they always start on their own line below the citation, two links sharing that line — Oct 2026, HTML-only, no CSS rule): peer-reviewed, thesis & dissertation, conferences. Author lists are AMS-style: the owner surname-first in bold (`Oguejiofor, C.N.`), coauthors as initials + surname with every known middle initial (`G.H. Bryan`, `R. Rotunno`, `P.P. Sullivan`, `D.H. Richter`, `C.E. Wainwright`, `J.E. Rudzin`), a serial comma and `and` before the last author, title and venue separated by a period. Dashes in venue/title text are spaced hyphens (` - `) site-wide; no en/em dashes anywhere
- `satellite-products.html` — portfolio grid (3 items, equal-height tiles; thumbnails CSS-cropped to a square frame) + modals with MP4s

**The navbar is duplicated verbatim in all 4 real pages** (no templating; links: Bio, Research, Publications, Satellite Products — rendered uppercase — then the search/theme icon controls). Any navbar change must be applied in all 4 files. Each page hardcodes `active` on its own nav link (and `js/agency.js` also sets it by filename). Contact info lives only in the footer, which is duplicated on all 4 pages.

## Build Commands

There is no npm toolchain (the former gulp pipeline — `package.json`, `package-lock.json`, `gulpfile.js`, `.travis.yml`, `.browserslistrc` — was removed in Aug 2026 to clear Dependabot alerts). The build uses the globally installed `sass` CLI and `terser`:

- `sass scss/agency.scss css/agency.css --load-path=node_modules` — compile CSS (this is what pages link)
- `sass scss/agency.scss css/agency.min.css --load-path=node_modules --style=compressed --no-source-map` — minified CSS (built but not linked)
- `terser js/agency.js -o js/agency.min.js --compress --mangle` — minify JS (pages load the **minified** file)

**Cache busters:** pages link `css/agency.css?v=N` and `js/agency.min.js?v=N`. After changing CSS or JS, bump the corresponding `?v=` in **all 4 pages** or GitHub Pages serves stale assets.

## Architecture

**Styles:** all custom styling lives in `scss/` (no inline `<style>` blocks in the HTML). Entry point `scss/agency.scss` imports:
- `base/` — `_variables.scss` (Bootstrap grays + `$primary: #fed136`), `_mixins.scss` (`$font-sans` Inter / `$font-serif` Source Serif 4; `serif-font` + `body-font` = serif, `heading-font` + `script-font` = Inter, `label-font` = small tracked-uppercase Inter 500 — see **Typography**), `_page.scss` (globals: serif body 18px / line-height 1.65 (17px ≤575.98px), `b, strong { 600 }`, `.section-heading` Inter 700 −0.03em, italic `.section-subheading` / `.bio-tagline`; `.bg-offwhite`; `ul.pub-list` gray boxes with `label-font` group titles over a hairline rule + nested `ul.pub-entries` hover-fill bullets; `.scholar-links`/`.scholar-link` profile pill buttons, explicitly Inter)
- `components/` — `_buttons.scss`, `_navbar.scss` (`#mainNav`, dark `$gray-900`; brand is Inter 700 with `rem` sizes so the 18px body doesn't inflate it; uppercase links whose tracking/padding are tuned to fit one line at 992–1199px — don't widen), `_theme.scss` (**dark mode + search overlay — imported last so overrides win**)
- `layout/` — `_masthead.scss` (dead), `_services.scss` (dead), `_portfolio.scss` (grids + modals; each tile's link+caption sit in a `.portfolio-card` wrapper carrying a 1px `#e8e8e8` hairline frame at rest (same as the bio timeline boxes) and, on hover, a `translateY(-4px)` lift with a soft `0 12px 24px rgba(0,0,0,.1)` shadow and the frame darkened to `#333` (Oct 2026, modeled on profconradi.com's `.gallery-item`; replaced the old `scale(1.02)` + 2px yellow ring — no scale, no yellow, nothing shifts); the template's `.portfolio-hover` yellow tint overlay and its `fa-plus` icon were removed in Sep 2026, so `a.portfolio-link` wraps only the `<img>`. **Equal-height tiles:** `.portfolio-item` is a column flexbox, the card `flex: 1` fills it and `.portfolio-caption` `flex: 1` absorbs the slack; the template's `max-width: 400px; margin: 0 auto` on link/caption is reset to `width: 100%; margin: 0` because auto cross-axis margins would disable flex stretch. Thumbnails are `display: block; object-fit: cover` with a per-page frame — `#research … img { aspect-ratio: 1200 / 920 }` (matches the files, no crop) and `#satellite-products … img { aspect-ratio: 1 / 1 }` (near-square sources, ≤4.5% trimmed per side). Caption `h4` is serif 600 1.05rem, `p` serif italic .95rem, trailing DOI `> a` is pinned to the caption bottom with `margin-top: auto`; modal `h2` is Inter 700 2.2rem (1.6rem on phones), `p.item-intro` and `p.item-note` (the closing "This work is currently published…" line, also `.text-muted`) share serif italic 1.08rem; `.modal-content` is `text-align: center`, and the `.modal-abstract` wrapper (abstract paragraphs + the `item-note`) overrides that with `text-align: left` while title/intro/image/button stay centered), `_timeline.scss` (`.bio-timeline` boxes: gray `#f5f5f5` fill, `#e8e8e8` border, 6px radius, bold, underlined, uppercase Inter heading at body size (`.bio-timeline-heading`) with 90px top margin; hover is a flat highlight with **no transform** (Oct 2026, replaced the old `scale(1.02)` pop) mirroring the `.github-link` pill: border `#333` + white fill + `0 1px 3px` shadow, dark mode border `#adb5bd` / fill `#3a3f44` (restated in `_theme.scss`'s own `:hover` rule because the dark rest-state rule out-specifies the light hover); degree marker is a 30px (26px on phones) `$gray-600` round badge holding the FA `fa-graduation-cap` glyph (`\f19d`, white) via `::before`, inset inside the box's top-left and centred on the title line; box text is left-aligned (`text-align: left` overrides `.team-member`'s centring) with a `56px` left gutter (`44px` on phones) reserving the badge's space; the vertical connector `.bio-timeline:before` sits at `left: 30px` (`23px` on phones) so it runs through the badge centres; the upstream `.timeline` block below line ~60 is unused), `_team.scss`, `_contact.scss` (targets `section#contact`, matched by nothing — dead), `_footer.scss` (`.footer h6` "Connect with me" label + social circles)

**Typography (Aug 2026):** modeled on https://www.eric-weinstein.com/ at the user's request — **Source Serif 4** for all body/prose/item text (18px, line-height 1.65, antialiased) and **Inter** for the navbar brand (700, −0.02em), page titles (`.section-heading`: 36px, 700, −0.03em), nav links, buttons, `.scholar-link` pills, the search input/label, and every small label via `label-font` (0.78rem, 500, uppercase, 0.18em tracking: publication-group titles, `.footer h6`). The bio's `.bio-timeline-heading` deliberately keeps its older bold + underlined uppercase Inter look at body size — the user found the small-label version too faint there. Item titles (`.portfolio-caption h4`, `.site-search-title`) are serif 600; descriptions/taglines (`.portfolio-caption p`, `.item-intro`, `.section-subheading`, `.bio-tagline`) are serif italic. Only Source Serif 4 400 / 400-italic / 600 and Inter 400–700 are loaded, from one Google Fonts `<link>` (plus two `preconnect` hints) just after the Font Awesome link in each page's `<head>` — bold text is pinned to 600. The site's own palette is kept (no accent-coloured underlines). Font Awesome glyphs set their own `font-family` on the `<i>`/`::before` and are unaffected.

**Dark mode:** an inline boot script in each page's `<head>` (just before the CSS link) applies `dark-mode` on `<html>` from `localStorage('theme')`, falling back to system `prefers-color-scheme` — this prevents a flash of the wrong theme. The navbar `#theme-toggle` button (moon/sun icon) toggles the class and persists the choice. All dark styles live in one `html.dark-mode` override block in `scss/components/_theme.scss` (palette: page `#1a1d21`, boxes `#2a2e33`, hairlines `#3a3f44`, text `#e9ecef`, muted `#adb5bd`; `$primary` yellow unchanged). Two gotchas there: the dark `.portfolio-card` rest rule (border `#3a3f44`) out-specifies the light `:hover`, so dark mode nests its own `&:hover` (border `#adb5bd`, shadow `rgba(0,0,0,.5)`); and because the leading `html` type selector gives every `html.dark-mode …` rule one extra point of specificity, a dark rest-state rule can silently beat a light-mode `:hover` rule (e.g. `ul.pub-entries > li::before` (0,3,5) vs the light `li:hover::before` fill (0,3,4)) — dark mode therefore carries its own `li:hover::before { background: $primary }` rule.

**Search:** the navbar `#search-toggle` button opens a client-side overlay built by `js/agency.js`. The searchable content is a **hand-maintained static index array (`searchIndex`) in `js/agency.js`** — when adding/changing site content, update the matching index entries and re-minify. Overlay styles are in `_theme.scss`.

**JavaScript:** `js/agency.js` (source) → `js/agency.min.js` (loaded). Handles: mobile-menu collapse on nav click, navbar shrink on scroll, active-link highlight, theme toggle, and the search overlay/index. `js/jqBootstrapValidation.js` is unused.

**Vendor assets:** checked into `vendor/` (Bootstrap, Font Awesome, jQuery, jQuery Easing). Font Awesome icons are used for the navbar search (`fa-search`) and theme (`fa-moon`/`fa-sun`) controls.

**Dead files:** `css/agency_old.css`, `css/agency.min_old.css`, `mail/`, `js/contact_me.js`, `js/jqBootstrapValidation.js`, `scss/layout/_masthead.scss`, `scss/layout/_services.scss`, `img/*_old*`.

**Analytics:** every real page carries inline GTM (`GTM-KDPB6FF`) and gtag (`UA-51796304-2`) snippets in `<head>`.

## Verifying changes

Theme choice persists across pages via localStorage. For the portfolio pages also confirm the three `.portfolio-card` heights match at desktop width and that hovering one lifts it 4px with a thin dark frame (no yellow); for navbar/type changes confirm the nav row stays on one line at 992–1200px.
